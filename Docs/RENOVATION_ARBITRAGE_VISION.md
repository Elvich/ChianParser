# 📸 ИИ-Анализ Фотографий и Арбитраж Ремонта (Renovation Arbitrage)

Этот документ описывает техническое решение для автоматического определения состояния квартир по фотографиям и расчета потенциальной прибыли от флиппинга (покупка "убитого" жилья -> ремонт -> продажа по рыночной цене готового).

---

## 👁️ 1. Визуальный анализ фотографий (Computer Vision / Multimodal LLM)

Для флиппинга критически важно находить квартиры в плохом состоянии ("убитые", под ремонт), так как именно на них можно получить максимальный дисконт при покупке.

### Схема работы ИИ-анализатора:
1.  **Сбор медиа:** При парсинге новой квартиры бэкенд скачивает ссылки на первые 5 фотографий объекта.
2.  **Запрос к Мультимодальной модели (например, Gemini 1.5 Flash / Claude 3.5 Sonnet / GPT-4o):**
    *   Модели передаются фотографии и системный промпт.
    *   *Промпт:* *"Проанализируй фотографии этой квартиры. Классифицируй состояние ремонта по шкале: 1. Ruined (убитая, под капремонт), 2. Grandma (бабушкин ремонт), 3. Cosmetic (косметика средняя), 4. Modern/Euro (свежий хороший ремонт), 5. Designer (дизайнерский). Верни JSON с категорией, процентом уверенности и списком дефектов (старые трубы, ободранные стены)."*
3.  **Сохранение метки:** В базу данных записывается `renovation_status` (от "Ruined" до "Designer") и `renovation_score`.

---

## 📈 2. Расчет спреда (Арбитраж ремонта)

Имея базу данных по району, мы можем автоматически рассчитать экономику проекта флиппинга для каждого объекта в плохом состоянии.

### Алгоритм расчета:
1.  **Поиск аналогов с хорошим ремонтом (Бенчмарк готового жилья):**
    *   Бэкенд находит в этом же доме (или в радиусе 1 км в аналогичных домах) квартиры той же комнатности, но со статусом ремонта `Modern/Euro` или `Designer`.
    *   Вычисляется медианная цена за квадратный метр готового жилья в этой локации: $P_{\text{ready\_meter}}$.
2.  **Оценка будущей стоимости объекта:**
    *   $V_{\text{target\_ready}} = \text{Площадь объекта} \times P_{\text{ready\_meter}}$
3.  **Экономика ремонта:**
    *   Инвестор задает в настройках среднюю стоимость ремонта за кв.м (например, $C_{\text{renovation\_meter}} = 25\ 000$ руб/м²).
    *   Стоимость ремонта объекта: $Cost_{\text{renovation}} = \text{Площадь} \times C_{\text{renovation\_meter}}$.
4.  **Расчет потенциальной прибыли (Спреда):**
    *   $\text{Spread} = V_{\text{target\_ready}} - \text{Цена покупки} - \text{Cost}_{\text{renovation}}$
    *   $\text{ROI \%} = \frac{\text{Spread}}{\text{Цена покупки} + \text{Cost}_{\text{renovation}}} \times 100\%$

## 📂 4. Смарт-подборка «Арбитраж Ремонта»
В боковом меню создается автоматическая смарт-подборка, куда попадают квартиры, соответствующие условиям:
*   Состояние: `Ruined` или `Grandma`.
*   Потенциальная прибыль (Spread) > `2 000 000` руб.
*   ROI > `15%`.
