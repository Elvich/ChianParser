# 📈 Нормализация спроса по комнатности (Demand Multipliers)

Этот документ описывает логику и формулы для гибкой настройки порогов спроса (просмотров за сегодня) в зависимости от типа квартиры (комнатности).

---

## 🏛️ Формула нормализации

Вместо создания индивидуальных порогов (Low, Market, Hot) для каждого типа жилья, мы вводим **базовые пороги спроса** и **коэффициент коррекции комнатности**:

$$\text{Normalized Views} = \frac{\text{Raw Views Today}}{\text{Room Coefficient}}$$

Где:
*   $\text{Raw Views Today}$ — сырое (или экстраполированное) число просмотров за сегодня от Циан.
*   $\text{Room Coefficient}$ — коэффициент (множитель) для конкретного типа комнатности квартиры, задаваемый в настройках:
    *   Студии: `1.5` (спрос выше ➡️ нормализованное значение ниже ➡️ требуется больше просмотров для Hot).
    *   1-комнатные: `1.0` (базовый уровень).
    *   2-комнатные: `0.8` (спрос ниже ➡️ нормализованное значение выше).
    *   3-комнатные: `0.6`.
    *   4+ комнатные: `0.4` (для Hot достаточно 100 просмотров, так как $100 / 0.4 = 250$).

## ⚙️ Изменение в моделях данных

### 1. На стороне Swift (Клиент macOS):
В объект `ScoringConfiguration` добавляются новые коэффициенты:

```swift
@Model
final class ScoringConfiguration {
    // Базовые пороги
    var baseDemandLow: Int = 30
    var baseDemandMarket: Int = 150
    var baseDemandHot: Int = 250
    
    // Коэффициенты коррекции (храним как Double)
    var coefStudio: Double = 1.5
    var coef1Room: Double = 1.0
    var coef2Room: Double = 0.8
    var coef3Room: Double = 0.6
    var coef4RoomPlus: Double = 0.4
}
```

### 2. На стороне Python (Сервер FastAPI):
В таблицу `ScoringConfiguration` в `database.py` добавляются соответствующие поля со значениями по умолчанию.

## 🎨 Дизайн интерфейса настроек (SwiftUI)

Вкладка «Спрос» в окне настроек:

```
+--------------------------------------------------------+
| БАЗОВЫЕ ПОРОГИ СПРОСА (1-комнатные квартиры)            |
| Низкий спрос (Low):    [ 30 ]  [+] [-]                 |
| Умеренный (Market):   [ 150 ]  [+] [-]                 |
| Горячий спрос (Hot):   [ 250 ]  [+] [-]                 |
+--------------------------------------------------------+
| КОРРЕКЦИЯ СПРОСА ПО КОМНАТНОСТИ                        |
| Студии:          [=============o--------]  150%        |
| 1-комнатные:     [==========o-----------]  100% (База) |
| 2-комнатные:     [========o-------------]   80%        |
| 3-комнатные:     [======o---------------]   60%        |
| 4+ комнатные:    [====o-----------------]   40%        |
+--------------------------------------------------------+
```
При перемещении слайдера или изменении степпера, настройки мгновенно отправляются по API `PUT /api/v1/scoring/config`, и сервер начинает рассчитывать `FlipScore` с учетом новых правил.
