# ChianParser

**ChianParser** — это мощный инструмент для парсинга и анализа объектов недвижимости с сайта Cian.ru. Проект включает в себя нативное приложение для macOS/iOS на Swift и серверную часть (Backend) на Python (FastAPI), управляющую обновлениями.

## Ключевые возможности

- **Детальный парсинг**: Сбор основных характеристик квартиры, информации о доме, расположения и статистики просмотров.
- **Отслеживание истории цен**: Автоматическое сохранение изменений цены объекта во времени.
- **Локальное хранилище**: Использование SwiftData для быстрого и безопасного хранения собранных данных локально.
- **Экспорт данных**: Возможность выгрузки собранной информации в форматах CSV и JSON для дальнейшего анализа.
- **Автоматические обновления**: Интеграция со Sparkle для бесшовного обновления macOS приложения (через собственный FastAPI Backend).

## Технологический стек

### Клиентская часть (App)
- **Язык**: Swift
- **UI Фреймворк**: SwiftUI
- **Хранение данных**: SwiftData
- **Архитектура**: MVVM (Model-View-ViewModel) с использованием контейнера внедрения зависимостей (`AppContainer`).
- **Библиотеки**: SwiftSoup (для fallback HTML-парсинга).

### Серверная часть (Backend)
- **Язык**: Python
- **Фреймворк**: FastAPI
- **База данных**: PostgreSQL (SQLAlchemy + asyncpg)

## Установка и запуск

### Запуск приложения (macOS/iOS)
1. Откройте `App/ChianParser.xcodeproj` в Xcode.
2. Дождитесь загрузки зависимостей (Swift Package Manager).
3. Выберите нужную схему (macOS или iOS) и нажмите `Cmd + R` для запуска.

### Запуск Backend-сервера
Сервер отвечает за отдачу appcast-файлов для системы обновлений Sparkle.
1. Перейдите в папку бэкенда: `cd Backend`
2. Создайте виртуальное окружение: `python3 -m venv .venv`
3. Активируйте его: `source .venv/bin/activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите сервер: `uvicorn main:app --reload`
